## Top 5 修复顺序

1. **W-UI-03**：先补 Windows 异常退出的 console control handler 与 mode/code page/ANSI 还原。它决定强杀或关闭窗口后是否留下不可用的控制台。
2. **W-UI-01 + W-UI-02**：重构 `term_mode.Saved`，保存和恢复 input/output mode 与 input/output code page；拆分 raw mode、VT、code page 三类失败，避免旧 conhost/ConPTY 上启动直接失败。
3. **W-UI-04 + W-UI-09**：把 Windows console input 统一到 `ReadConsoleInputW` 事件层，消费 resize/focus/mouse 记录，把 Unicode 字符转成 UTF-8，再喂现有 VT 字节解析器。它同时修 resize、中文/emoji/IME、事件堆积。
4. **W-UI-10**：恢复 Windows 的 exe/VT 单测 step 并加 Windows CI。没有这一步，前三项修复没有自动回归保障。
5. **W-UI-06 + W-UI-08**：实现或明确降级 Windows 剪贴板，并让 `doctor --json` 报告 console mode、VT、code page、clipboard、sound、notification 健康状态。完成用户可见能力与诊断闭环。
