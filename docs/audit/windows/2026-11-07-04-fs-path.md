## Top 5 修复顺序

1. **W-FS-06**: 统一 Windows 目录 sync 契约，先消除首次创建锁文件与私有目录时的 `OperationUnsupported` 用户可见失败，再定义 rename 后目录项恢复策略。

5. **W-FS-17**: 加 Windows CI 与 Windows 专用崩溃恢复测试，让前四项有持续回归防线。
